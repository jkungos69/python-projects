# 🛒 Basic Shopping Cart Program

A beginner-friendly Python program that demonstrates the fundamental concepts of **Variables**, **User Inputs**, and **Basic Arithmetic Operations** through a simple terminal-based receipt generator.

---

## 📌 Features

- **Interactive Inputs:** Accepts item name, unit price, and quantity directly from the user via the terminal.
- **Automatic Calculations:** Computes the subtotal, applies a standard 10% discount, and calculates the final total amount due.
- **Formatted Output:** Displays a clean, structured receipt in the console.

---

## 🛠️ Python Concepts Applied

- **Variables:** Storing user inputs and calculated results.
- **Data Types & Type Casting:**
  - `str` (String) for item names.
  - `float` (Decimal) for prices and financial calculations.
  - `int` (Integer) for product quantities.
- **Basic Arithmetic:** Multiplication (`*`) and subtraction (`-`).
- **Input/Output Handling:** `input()` function for user interaction and `f-strings` for clean output formatting.

---

## 💻 How to Run

1. Make sure **Python 3.x** is installed on your computer.
2. Open your terminal or VS Code in the project directory.
3. Run the script using:


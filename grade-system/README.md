# Grade System

Simple Python program for checking a student's grade and showing the final remark.

## Features

- Asks for the student's name
- Asks for the student's section
- Accepts a grade from 0 to 100
- Shows a report with the student's grade remark

## Grade Remarks

| Grade Range | Remark |
| --- | --- |
| 90 - 100 | Excellent |
| 85 - 89 | Very Good |
| 80 - 84 | Good |
| 75 - 79 | Passed |
| 0 - 74 | Failed |
| Below 0 or above 100 | Invalid Grade |

## How to Run

Open PowerShell or terminal, then go to the project folder:

```powershell
cd C:\Users\Kevin\python-projects\grade-system
```

Run the program:

```powershell
python main.py
```

```text
Student Name: Kevin
```
